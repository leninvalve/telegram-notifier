# Telegram notifier
Send messages from Debian to Telegram app via curl.

## Requirements
1. curl installed.
2. token (provided by Telegram).
3. chat_id (provided by Telegram).
4. ~/.telegram (with above information and 600 permissions). Example of ~/.telegram file:
```bash
_TG_TOKEN="7873824:ASDD..."
_TG_CHAT_ID="2738781"
```
